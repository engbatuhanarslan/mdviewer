# Local MD'ye hoş geldin 👋

Markdown dosyalarını **tamamen cihazında** aç, düzenle ve oku. Başlamak için üstteki **Dosya aç** düğmesini kullanabilir veya bir `.md` dosyasını pencereye sürükleyebilirsin.

## Neler yapabilirsin?

- [x] Canlı Markdown önizleme
- [x] Dosya açma ve sürükle-bırak
- [x] İçindekiler ve belge araması
- [x] Koyu / açık tema
- [x] Markdown, HTML ve PDF çıktısı
- [x] Otomatik yerel taslak kaydı

> Gizlilik notu: Dosyaların hiçbir sunucuya gönderilmez. Her şey bu tarayıcı sekmesinde işlenir.

### Kod örneği

```javascript
const güvenli = "Dosyam yerelde kalıyor";
console.log(güvenli);
```
